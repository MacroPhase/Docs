# Backup and Restore

MacroPhase stores everything locally. This means backups are your responsibility — but the app makes it straightforward.

## Exporting

1. **More → Profile Settings → Data Management**
2. Tap **Export Data**
3. Choose scope: full backup, food log only, or weight only
4. Share the file (email, cloud storage, etc.)

The backup is a CSV or JSON you can open in any spreadsheet app.

## Importing

### From MacroPhase

1. **More → Profile Settings → Data Management**
2. Tap **Import Data**
3. Select your file
4. Choose **Merge** (add new, skip duplicates) or **Replace** (fresh start)

### From MacroFactor

1. Export from MacroFactor as CSV
2. In MacroPhase: **More → Profile Settings → Data Management**
3. Tap **Import from MacroFactor**
4. Select the files

The importer maps MacroFactor's format to MacroPhase's schema.

### From Other Apps

Standard CSV formats (food name, calories, protein, fat, carbs, date) usually work. The AI coach can help parse unusual formats.

## Moving to a New Device

1. **Export** from old device
2. **Send** file to new device
3. **Install** MacroPhase
4. **Import** the backup

Settings and API keys need to be reconfigured (not included in export for security).

## What's Included

**Included:** Food logs, weight, custom foods, favorites, recipes, body metrics, photos, memory, conversations, check-ins, settings.

**Not included:** API keys, theme settings, device preferences.

## Automatic Backups

Android may include MacroPhase in system backups to Google. Not guaranteed across all devices.

> 💡 **Key Idea**
> Don't rely solely on automatic backups. Export manually before app updates or device switches. It takes 30 seconds and prevents headaches.

## Data Safety

Backups are plain files — treat them as sensitive. Don't share publicly. Store in encrypted locations.
